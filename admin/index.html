Paramètres

Mot de passe, données et boutique

🔐 Changer le mot de passe admin

Le mot de passe est défini dans le fichier admin.html ligne const ADMIN_PASS. Pour le changer durablement, éditez ce fichier. Ici vous pouvez le changer pour cette session (stocké en localStorage).

💾 Données

Les produits et niches sont stockés dans votre navigateur (localStorage). Utilisez Export pour sauvegarder un fichier JSON.

🏪 Boutique

👁 Ouvrir la boutique →

Les modifications dans l'admin apparaissent instantanément dans la boutique (même navigateur). Sur un autre appareil, importez le JSON exporté.
